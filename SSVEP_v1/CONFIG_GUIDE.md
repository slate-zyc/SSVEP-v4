# config.json 参数详细说明

本文逐项解释当前 `config.json` 的 **33 个键**，说明其实际代码用途、单位、影响范围和修改限制。

本说明对应当前项目实现，不表示每个参数都是论文明确公布的原作者配置。尤其是 IFB-OCN 的网络参数搜索采用重建版方案，具体依据及限制见 `REPRODUCTION.md`。

## 1. 配置如何进入程序

`data_io.py` 的 `read_config()` 将 JSON 解析为 Python 字典。代码中的 `config["fs"]` 就表示读取键 `fs` 对应的值。

在 PyCharm 直接运行 `main.py` 时，默认读取项目目录中的 `config.json`。指定 `--config` 可以读取其他配置文件；但数据、结果和缓存的相对路径仍以 `data_io.py` 所在的项目目录为基准，不会改为相对新配置文件所在目录。

当前项目目录：`E:\Codex\asyn-SSVEP\SSVEP_v1`。

JSON 书写规则：

- 字符串及键名使用英文双引号。
- 列表使用方括号，列表成员之间使用逗号。
- 最后一项后面不能加多余逗号。
- 不能加入 `#`、`//` 注释，也不能加入 Python 的三引号说明。
- 默认数据路径使用 `../EEG_data`，程序以版本目录为基准解析，项目整体移动后仍可使用。
- 如需指定本机绝对路径，可写成 `E:/Codex/asyn-SSVEP/EEG_data`；JSON 中使用反斜杠时须写成 `E:\\Codex\\asyn-SSVEP\\EEG_data`。
- 本项目没有完整的配置模式校验；“JSON 可以解析”不代表“任意参数组合都能正确运行”。

## 2. 参数总览

|分类|键|主要影响|

|实验对象|`subjects`|参与运行的受试者|

## 3. 实验对象与目录

### 1. `subjects`

- **当前值**：`["S01", "S02", …, "S24"]`。这里的省略号仅用于说明，实际 JSON 中列出了全部24个字符串。
- **类型**：字符串列表，无物理单位。
- **含义**：本次运行包含哪些受试者，以及逐人运行的顺序。
- **代码位置**：`main.py` 的 `main()`，随后传入数据检查、质量分析和两类分类实验。

例如 `["S01", "S02"]` 只处理这两名受试者；其余人的文件不会自动加入实验。各受试者仍独立训练和测试，不会因为列表同时包含多人就把他们混成一个训练集。

每个编号必须对应数据目录下的受试者文件夹，并具有四种状态的 MAT 文件。编号不能重复。

**命令行优先级**：`--subjects S01 S02` 覆盖本次实际运行对象，不修改 JSON 文件，并使输出进入独立的 `runs` 子目录。

### 2. `data_dir`

- **当前值**：`"../EEG_data"`。
- **类型**：路径字符串。
- **含义**：原始 EEG 数据及通道表所在目录。
- **当前实际路径**：`E:\Codex\asyn-SSVEP\EEG_data`；与四个版本目录同级。

目录下需要包含 `S01` 等受试者文件夹，以及 `Channel Loc.xlsx`。例如程序会按规则寻找：

```text
../EEG_data/S01/sub_01_data_CS.mat
../EEG_data/S01/sub_01_data_NS1.mat
```

可以将它改成外部磁盘上的绝对路径，程序仍按同样的文件组织规则读取。这个键只改变读取位置，不搬运或下载文件。`Subjects' Info.xlsx` 可放在该目录，但当前算法不使用人口学信息进行预测。

### 3. `output_dir`

- **当前值**：`"results_full"`。
- **类型**：路径字符串。
- **含义**：实验预测、指标、图表、报告和运行记录的输出目录。
- **代码位置**：`main.py`、`evaluation.py`、`asynchronous.py`、`quality_analysis.py`、`reporting.py`。

直接使用默认配置运行时，结果写入项目内的 `results_full`。同一目录下的同名输出会被对应阶段重新生成。

显式传入 `--subjects` 或 `--windows` 时，主程序会在这个目录下附加 `runs/受试者与窗长标识`。

进行另一套参数实验时，可使用独立的输出目录，避免不同参数的结果相互覆盖。改变输出目录不会改变算法数学定义。

### 4. `cache_dir`

- **当前值**：`"cache"`。
- **类型**：路径字符串。
- **含义**：预处理数组、63通道平均响应和 OCN 候选特征的缓存目录。

缓存使后续运行可以跳过重复的 MAT 解压、降采样和网络特征计算。它不是最终实验报告，也不是训练好的分类器文件。

缓存文件名含来源和参数标识，参数变化后可能生成另一组缓存。改变这个目录只改变缓存读写位置，不会自动移动已有缓存。

## 4. 采样率、类别和通道

### 5. `original_fs`

- **当前值**：`5000`。
- **单位**：Hz，即每秒采样点数。
- **含义**：原始 MAT 数据真实的采样率。
- **代码位置**：`data_io.py` 的 `preprocess()` 与 `cache_key()`。

例如，22500个采样点在5000Hz下代表 `22500 / 5000 = 4.5秒`。

这个值描述已有数据的属性，不能为了节省计算而随意改小。填写错误会导致时间轴和滤波处理的物理解释错误。

当前重采样实现要求 `original_fs` 能被 `fs` 整除。数据检查还固定使用本数据集的数组维度；更换其他采样率的数据时，需要同时审查数据读取和校验代码。

### 6. `fs`

- **当前值**：`250`。
- **单位**：Hz。
- **含义**：降采样后，后续截窗、滤波和参考信号使用的采样率。

当前降采样倍数为 `5000 / 250 = 20`，因此一秒信号有250个点，四秒有1000个点。

该参数同时用于以下计算：

- 将秒换算为数组下标；
- 设计陷波和子带滤波器；
- 构造正余弦参考信号；
- 将 NS 切成一秒窗；
- 计算频谱横轴；
- 将 OCN 延迟点数换算成实际时间。

**修改限制**：应使用正整数，并满足重采样的整数倍要求。所有滤波边界及参考谐波必须低于 `fs/2`。当前最高阻带边界为90Hz，因此不能单独把 `fs` 降到180Hz或更低后继续使用相同滤波配置。

### 7. `frequencies`

- **当前值**：`[8, 9, 10.5, 11, 12, 13, 14, 15]`。
- **单位**：Hz。
- **含义**：原始 CS 类别轴对应的刺激频率，同时决定 FBCCA 参考信号。

对应关系为：

|类别编号|频率|
|---:|---:|
|0|8Hz|
|1|9Hz|
|2|10.5Hz|
|3|11Hz|
|4|12Hz|
|5|13Hz|
|6|14Hz|
|7|15Hz|

**顺序具有数据语义，不能随意排序或交换。** 改列表顺序不会自动重新排列 MAT 中的类别轴。

当前异步分类和结果校验有八类结构约束，质量分析也会通过 `.index(12)` 寻找12Hz目标。因此不能仅删除列表元素就实现“只识别部分频率”。

S11的疑似类别顺序异常记录在 `DATA_AUDIT.md`，主实验没有为它单独修改本列表。

### 8. `channels`

- **当前值**：`["Pz", "PO7", "PO3", "POz", "PO4", "PO8", "O1", "Oz", "O2"]`。
- **类型**：电极名称列表。
- **含义**：频率识别和 FS 异步分类所使用的后部电极，以及它们在处理数组中的顺序。

程序通过官方通道表寻找这些名字，匹配时忽略大小写，例如 `POz` 与表中的 `Poz` 可以对应。不存在的名称会导致错误，不会自动挑选一个相近电极。

改变电极组合会改变空间滤波和识别结果，并生成不同的预处理缓存。

**作用边界**：

- IFB-OCN 重建版独立读取硬编码的 `Fp1`，不是由本列表决定；
- 质量分析独立处理63通道，不会因本列表只有九个电极而只生成九通道地形图。

## 5. 时间设置

### 9. `windows`

- **当前值**：`[1, 2, 3, 4]`。
- **单位**：秒。
- **含义**：频率识别分别使用多长的 EEG 数据进行判断。

四种窗长会独立运行，产生四套识别结果。它们不是把一个试次连续分成1秒、2秒、3秒、4秒四段，而是从同一个起点分别截取不同长度。

例如延迟0.14秒时：

|窗长|实际截取区间|
|---:|---|
|1秒|0.14–1.14秒|
|2秒|0.14–2.14秒|
|3秒|0.14–3.14秒|
|4秒|0.14–4.14秒|

当前主程序要求窗长唯一、正数且不超过4秒；特别短的窗还可能不满足滤波所需的最小样本长度。稳妥的复现范围是当前1–4秒。

`--windows` 可覆盖本次频率识别设置。**它不会改变异步分类固定的一秒窗，也不会改变质量频谱使用的四秒窗。**

### 10. `delay_seconds`

- **当前值**：`0.14`。
- **单位**：秒，即140毫秒。
- **含义**：截取 CS 识别信号时，从刺激起点向后跳过的时间。
- **代码位置**：`data_io.py` 的 `crop_cs()`，以及 ITR 和质量图的相关逻辑。

当前起始下标为 `round(0.14 × 250) = 35`。一秒窗的 Python 切片为 `35:285`，包含250个点。

它同时影响：

1. 频率识别的 CS 截取起点；
2. 异步分类的 CS 截取起点；
3. ITR计入的视觉延迟；
4. 质量图上的延迟标记；
5. OCN候选特征缓存的签名。

NS片段从各原始epoch自身的起点切分，不额外跳过这0.14秒。质量分析的四秒频谱也仍取0–4秒，图中标记不等于对质量数据重新截窗。

修改时应保证延迟非负，且 `延迟+最大窗长` 不超过原始CS的4.5秒时长。当前4秒窗延伸至4.14秒，这一选择是显式复现假设。

### 11. `cue_seconds`

- **当前值**：`1.5`。
- **单位**：秒。
- **含义**：计算频率识别 ITR 时计入的提示时间。

当前决策总时长为：

```text
T = window_seconds + cue_seconds + delay_seconds
```

一秒识别窗对应 `T = 1 + 1.5 + 0.14 = 2.64秒`。

在准确率相同的情况下，计入的时间越长，ITR越低。**这个键只影响当前实现的 ITR 时间计算，不会从原始 CS 中再删除1.5秒，也不改变分类预测。**

## 6. FBCCA参考与滤波器组

### 12. `harmonics`

- **当前值**：`3`。
- **类型**：正整数。
- **含义**：为每个刺激频率构造参考信号时，包含多少阶谐波。
- **代码位置**：`algorithms.py` 的 `reference_bases()`。

对于12Hz，当前参考包含12、24、36Hz，每个频率各有正弦和余弦，因此参考矩阵有 `2×3=6` 行。

这个参数同时影响独立 FBCCA 和 FS 融合版中的 CCA 特征；不改变 TRCA 的训练模板。

每个参考谐波必须严格低于 `fs/2`，否则程序会报错。它不是质量分析的谐波数量开关：质量图仍固定分析12、24、36、48Hz四个频点。

### 13. `filter_passbands`

- **当前值**：`[[6,80], [14,80], [22,80], [30,80]]`。
- **单位**：Hz。
- **含义**：四个滤波器组子带的通带边界。

例如第一子带主要保留6–80Hz，第二子带主要保留14–80Hz。每个子带分别提取相关特征，随后融合。

它用于后部电极的 FBCCA、TRCA/eTRCA 及 FS 特征，不是 OCN 的五个候选频带，也不是质量图显示用的7–70Hz滤波。

**当前异步实现有四子带的数组结构约束，不能只把列表改成三项或五项。** 修改子带数量需要同步修改异步特征维度和数组重排代码。

### 14. `filter_stopbands`

- **当前值**：`[[4,90], [10,90], [16,90], [24,90]]`。
- **单位**：Hz。
- **含义**：与每个通带对应的阻带边界，用于确定滤波器阶数。

例如第一带：

```text
低侧阻带边界4Hz → 通带下边界6Hz
通带上边界80Hz → 高侧阻带边界90Hz
```

4–6Hz和80–90Hz是过渡区域，不应把阻带边界误认为另一个通带。

必须与 `filter_passbands` 一一对应，通常满足：

```text
0 < 低侧阻带 < 低侧通带 < 高侧通带 < 高侧阻带 < fs/2
```

当前代码通过 `zip()` 配对，列表长度不一致时可能只处理较短列表的部分，随后产生维度问题，因此两者都应保持四项。

### 15. `cheb_order_ripple_db`

- **当前值**：`3`。
- **单位**：dB。
- **含义**：传给 `cheb1ord()` 的通带最大衰减规格，用于求滤波器阶数和临界频率。

它参与“需要多高阶滤波器”的计算，不直接等同于最终创建滤波器时的纹波参数。

当前设置与下面的 `cheb_ripple_db=0.5` 是两个独立调用中的参数，不能因为名称相似而把它们视为同一个值。

### 16. `cheb_ripple_db`

- **当前值**：`0.5`。
- **单位**：dB。
- **含义**：传给 `cheby1()` 的通带纹波参数，用于实际构造 Chebyshev I 滤波器。

这里的纹波表示通带幅频响应允许的起伏。它不是“去除0.5Hz信号”，也不是噪声幅度阈值。

程序随后使用双向零相位滤波，最终幅频响应还受到双向处理影响。因此设计规格与最终响应应区别理解。

### 17. `stop_attenuation_db`

- **当前值**：`40`。
- **单位**：dB。
- **含义**：`cheb1ord()` 求阶数时要求的阻带衰减规格。

40dB对应幅度比例约0.01的衰减量级。更严格的阻带要求通常需要更高阶滤波器，但实际阶数也由通带、阻带和采样率共同决定。

本键是设计阶段的规格；最终响应还取决于实际纹波设置及双向滤波，不能单看该键就保证每个频点都正好衰减40dB。

### 18. `notch_q`

- **当前值**：`30`。
- **类型**：正数，无量纲。
- **含义**：预处理50Hz陷波器的品质因数Q。
- **代码位置**：`data_io.py` 的 `preprocess()`。

单次陷波设计的近似带宽关系为 `带宽≈中心频率/Q`。当前约为 `50/30≈1.67Hz`。Q越高通常越窄，Q越低通常越宽；最终程序还会做双向滤波。

中心频率50Hz写在代码中，并不由这个键改变。改变Q会使预处理缓存键变化，并影响后续多种分析。

## 7. 子带评分与TRCA稳定性

### 19. `weight_exponent`

- **当前值**：`-1.25`。
- **类型**：浮点数。
- **含义**：子带权重公式中子带编号的指数。

与 `weight_offset` 一起构成：

```text
w(m) = m ** weight_exponent + weight_offset
m = 1, 2, 3, 4
```

当前四个权重约为 `[1.25, 0.6704, 0.5033, 0.4268]`。较低编号子带获得较高权重。

它影响频率识别的融合得分，也影响 FS 框架确定候选频率的步骤。该键不参与 OCN 的频带选择。修改时建议保持浮点数形式；不要将它当作需要遍历测试集寻找最大准确率的自由参数。

### 20. `weight_offset`

- **当前值**：`0.25`。
- **类型**：浮点数。
- **含义**：在每个子带权重的幂函数项之后增加的常数。

它可以避免较高编号子带的权重衰减过小。增大偏移会让子带间的相对权重更接近，但不会把权重自动归一化到和为1。

它与 `weight_exponent` 必须一起理解，作用于子带相关特征的融合，不是加在原始 EEG 上的直流偏置。

### 21. `score_power`

- **当前值**：`1`。
- **含义**：独立频率识别时，相关系数在加权前采用的幂次。

当前评分形式为：

```text
score(class) = sum_m [w(m) × correlation(m, class) ** score_power]
```

`1`表示线性融合；`2`表示平方后融合。两者对 TRCA 中负相关的处理不同：线性保留符号，平方会将负值变成正值。

此键同时用于独立 FBCCA、TRCA、eTRCA。FS候选频率的幂次由另一个键 `fs_score_power` 控制。

建议只在明确设计的比较中使用1或2；当前代码不会为任意小数幂处理负相关，随意填小数可能产生无效数值。

### 22. `trca_ridge_relative`

- **当前值**：`1e-8`，即0.00000001。
- **类型**：正数，无量纲的相对系数。
- **含义**：TRCA广义特征值问题中，对协方差矩阵施加的微小正则化强度。

实际加到矩阵对角线上的量为：

```text
ridge = trca_ridge_relative × trace(Q) / 通道数
Q_regularized = Q + ridge × 单位矩阵
```

其中Q是训练试次的协方差和。相对迹尺度使正则化随信号整体尺度变化，主要用于避免矩阵奇异和数值不稳定。

它影响独立TRCA/eTRCA及FS使用的TRCA模型，不影响纯FBCCA参考信号。

**当前代码要求计算出的ridge大于0，因此不能把该键设为0并期待它代表“关闭正则化”。** 它也不是线性SVM的C参数。

## 8. 交叉验证与FS框架

### 23. `seed`

- **当前值**：`20261104`。
- **类型**：整数，无物理单位。
- **含义**：OCN内层 `StratifiedGroupKFold` 随机划分的随机种子。

相同输入、种子和软件条件有助于得到相同的内层划分。它不表示随机抽取24名受试者，也不控制外层原始试次的模12分组。

单元测试中另外定义的随机种子不由这个键控制。改变种子可能改变OCN选参、选带和最终预测，不应只保留对测试结果最有利的种子。

### 24. `folds`

- **当前值**：`12`。
- **类型**：整数。
- **含义**：异步分类外层验证使用的折数。

CS每个频率有12次重复，当前异步协议要求 `folds` 与重复次数完全一致。NS按原始试次编号对折数取模，保证同一原始试次的所有片段同折。

当前每折测试包含8个CS和8个NS片段。

**这个键不是可以直接切换成5折或10折的通用开关。** 异步程序会检查它必须等于12；独立频率识别则直接使用数据的重复数生成12折，并不读取这个键决定折数。

### 25. `fs_score_power`

- **当前值**：`2`。
- **含义**：FS框架确定候选频率时，对eTRCA各子带相关系数采用的幂次。

当前先计算 `sum_m [w(m) × correlation(m, class)^2]`，再选择得分最高的候选频率，随后调用该频率的LDA判断CS/NS。

它与 `score_power` 的区别是作用场景：

|键|作用场景|
|---|---|
|`score_power`|独立八分类频率识别|
|`fs_score_power`|FS异步框架的候选频率确定|

它不会把输入LDA的所有相关特征都自动平方；LDA仍接收子带相关特征本身。

### 26. `lda_shrinkage`

- **当前值**：`"auto"`。
- **类型**：当前为字符串，直接传给LDA的收缩参数。
- **含义**：控制FS分类器的协方差收缩方式。

FS需要为每个频率训练一个LDA。样本有限、特征相关时，协方差估计可能不稳定，收缩会使估计更稳定。`"auto"`让分类器自动估计收缩强度，不是根据外层测试准确率挑选强度。

当前求解器固定为 `lsqr`，CS/NS先验固定为各0.5，这两项不在JSON中。修改本键必须符合该求解器支持的参数格式，并在报告中记录方法变化。

根据当前安装版本的分类器说明，支持的值为：

|JSON写法|含义|
|---|---|
|`"auto"`|使用Ledoit–Wolf方法自动估计收缩强度|
|`null`|解析为Python的None，不采用收缩|
|0到1之间的数值，例如`0.2`|使用固定收缩强度|

这些是接口支持的取值，不表示更改后必然改善识别结果。

## 9. IFB-OCN重建版参数

以下键仅针对本项目的 `IFB-OCN-reconstructed`。网络参数采用训练内网格搜索，不应解释为已经确认的原作者完整优化规则。

### 27. `ocn_bands`

- **当前值**：`[[0.5,3], [4,7], [8,13], [13,30], [30,60]]`。
- **单位**：Hz。
- **含义**：Fp1网络法要比较的五个候选频带。

|候选编号（从0开始）|频带名称|范围|
|---:|---|---|
|0|delta|0.5–3Hz|
|1|theta|4–7Hz|
|2|alpha|8–13Hz|
|3|beta|13–30Hz|
|4|gamma|30–60Hz|

每个频带使用代码中固定的四阶Butterworth零相位带通，再分别构建递归网络。它与后部九通道使用的四个 `filter_passbands` 子带是两套设置。

改变这些边界会改变网络候选特征，进而影响内层选带与最终预测。所有边界必须位于0和 `fs/2` 之间。

### 28. `ocn_delays`

- **当前值**：`[2, 4]`。
- **单位**：降采样后的采样点数，不是秒。
- **含义**：延迟嵌入的时间间隔候选。

在250Hz下：

- 2个点 = 0.008秒 = 8毫秒；
- 4个点 = 0.016秒 = 16毫秒。

与CS截取延迟 `delay_seconds=0.14秒` 完全不同：前者决定网络节点如何构成，后者决定从哪个时刻开始取EEG片段。

应使用正整数；如果改变 `fs` 而不改这些点数，实际嵌入时间间隔也会改变。

### 29. `ocn_dimensions`

- **当前值**：`[3, 5]`。
- **类型**：正整数列表。
- **含义**：每个延迟状态向量包含多少个时间位置的数值。

维数为m、延迟为τ时，一个网络节点形如：

```text
[x(t), x(t+τ), …, x(t+(m-1)τ)]
```

它不是电极数量，也不是最终SVM输入维数。

对于N个采样点，可构造的节点数为 `M=N-(m-1)τ`。例如一秒250点、m=5、τ=4时，得到234个节点，状态向量覆盖64毫秒的时间跨度。

维数和延迟过大可能导致剩余节点不足，程序会报错。

### 30. `ocn_radii`

- **当前值**：`[0.5, 1.0]`。
- **单位**：逐片段标准化后的状态空间距离，无原始EEG幅值单位。
- **含义**：决定两个延迟状态向量是否连接的欧氏距离阈值候选。

在构图前，每个片段独立减均值并除以自身标准差。若两个节点的欧氏距离不超过半径，就建立连接；不保留自环。

较小半径通常使网络更稀疏，较大半径通常使网络更稠密。它不是滤波频率，也不是CS/NS分类阈值。

当前参数组合总数为：

```text
2种延迟 × 2种嵌入维数 × 2种半径 = 8组
```

每组提取平均度和平均聚类系数两个特征；最佳组合由外层训练数据内的验证选择。

### 31. `ocn_inner_folds`

- **当前值**：`3`。
- **类型**：整数。
- **含义**：OCN在每个外层训练集中选择网络参数和频带时，使用的内层验证折数。

外层测试样本先被留出，再对其余训练样本做3折分层分组验证。每个内层拟合集独立拟合StandardScaler和SVM，不能使用外层测试样本拟合缩放参数。

内层验证用于选择参数；外层测试用于评价选好参数后的模型，两者不能混淆。

折数增大会增加训练次数，还必须满足类别和原始分组数量的约束。它不会把外层12折也改成3折。

### 32. `ocn_svm_c`

- **当前值**：`1.0`。
- **类型**：正数。
- **含义**：线性SVM的误分类惩罚系数C。

一般而言，较大的C更强调减少训练错误；较小的C对错误的惩罚较轻，正则化约束相对更强。但改变它不保证测试准确率单调提高。

当前C同时用于内层候选比较和最终外层SVM，不是一个由程序进一步搜索的C候选列表。SVM核固定为线性核，前置StandardScaler仅在对应训练数据上拟合。

### 33. `ocn_top_bands`

- **当前值**：`3`。
- **类型**：整数。
- **含义**：每个外层训练折中，选取内层成绩最高的几个候选频带。

程序先为每个频带选择其最佳网络参数，再按内层准确率排列频带，取前三个。每带提供平均度和聚类系数两个特征，因此最终输入SVM的是六维向量。

```text
最终特征维数 = ocn_top_bands × 2
```

合理设置应在1到候选频带总数之间。当前代码切片操作不会统一为超出范围的数值提供友好校验，不应将其设为0、负数或超过5并期待预期行为。

## 10. 哪些参数可以直接改，哪些不能单独改

|需求|可调整项|必须注意|
|---|---|---|
|只运行部分受试者|`subjects`或`--subjects`|文件必须齐全；改变实验人数后应重新生成对应汇总|
|只运行1秒和2秒频率识别|`windows`或`--windows`|不改变异步分类的一秒窗|
|更换数据存储磁盘|`data_dir`|目录结构与通道表仍需符合本数据集要求|
|另存一组参数实验|`output_dir`|不会自动搬运数据或已有结果|
|调整参考谐波数|`harmonics`|最高参考频率低于奈奎斯特频率；属于方法变动|
|比较不同电极组合|`channels`|只影响后部通道方法；OCN的Fp1仍固定|
|改变采样率|`fs`|需联动滤波边界、谐波、时间下标和OCN延迟物理时长|
|减少刺激类别|不能只改`frequencies`|需同步选择数据类别并修改八类结构、报告与验证代码|
|改变滤波器组数量|不能只改两个子带列表|异步特征与reshape目前按四子带组织|
|改成5折外层验证|不能只改`folds`|当前异步协议要求12次重复对应12折|

## 11. 参数修改与缓存、续算、结果的关系

三种机制需要区分：

1. **预处理缓存键**：考虑采样率、陷波Q、所选通道、源文件属性、通道表和预处理版本等；不因单独改变子带权重就必然重做降采样。
2. **OCN候选缓存键**：额外考虑所有 `ocn_` 开头的配置和CS截取延迟。当前实现中，即使某些字段只用于分类，也会进入该缓存签名。
3. **阶段完成签名**：考虑完整配置、窗长、相关源文件属性、通道表以及项目根目录下所有Python源码。因此修改源码注释也可能触发 `--resume` 重新计算。

修改本说明文档本身不会改变Python源码签名。

不要修改参数后只运行 `--stage report`，就认为对应模型已经重新训练。报告阶段主要读取已有预测与指标；影响计算的参数变化后，应重新运行相应实验阶段。

## 12. 三个具体例子

### 示例A：检查单名受试者的一秒流程

在项目目录终端执行：

```powershell
python main.py --subjects S01 --windows 1
```

这会运行S01的数据检查、质量分析、1秒频率识别和固定1秒异步分类，结果进入独立运行目录；不是只运行频率识别。

### 示例B：只运行指定频率识别窗长

```powershell
python main.py --stage frequency --windows 1 2
```

这会对配置中的受试者运行1秒和2秒八分类，不执行异步分类。

### 示例C：理解一秒FS分类的数据流

```text
fs=250、delay_seconds=0.14
→ CS从下标35开始取250点
→ 四个滤波器组分别计算eTRCA相关
→ fs_score_power=2，平方加权确定候选频率
→ 对应频率的LDA接收四维特征
→ 融合版再加入四个CCA特征，形成八维输入
→ LDA接受则输出候选频率，否则输出NS
```

这条流程不由 `ocn_radii` 或 `ocn_svm_c` 控制；它们属于独立的网络法分支。
