## 1. 先记住两件事

### 1.1 数组形状约定（全项目唯一）

```
最后一个轴   = 时间
倒数第二个轴 = 通道
```

具体到各个阶段：

| 数据 | 形状 | 含义 |
|---|---|---|
| 原始 CS 文件 | `[8, 63, 22500, 12]` | 频率、通道、时间、重复（MATLAB 顺序） |
| 预处理后 CS | `[8, 12, 9, 1125]` | 频率、重复、通道、时间（4.5 s @ 250 Hz） |
| 预处理后 NS | `[24, 9, 1000]` | 原始试次、通道、时间（NS3 是 `[48, 9, 500]`） |
| 子带滤波后 | `[4, ...]` | 最前面多一维“子带” |
| 截 4 秒窗后 | `[4, 8, 12, 9, 1000]` | 子带、频率、重复、通道、时间 |
| FBCCA 相关 | `[4, 8]` | 子带、候选频率 |
| eTRCA 特征 | `[样本, 8, 4]` | 样本、候选频率、子带 |

> 命名习惯：`bank`（子带堆叠）、`trial`（一个试次）、`window`（截好的窗）、
> `model`（模板 + 空间滤波器）。看到这些词就能对上号。

### 1.2 两个任务的区别

```
频率识别（图5/6）：有同步提示，判断“刚才闪的是哪个频率”。     8 分类
异步分类（图7）： 没有提示，随时判断“现在是什么状态”。
    ├─ FS 系列：8 个频率 + 空闲 = 9 分类
    └─ IFB-OCN：只判断 连续闪烁(CS) / 空闲(NS) = 2 分类
```

CS = 连续闪烁刺激（有目标），NS = 空闲/无目标状态。三类 NS 是三种不同的空闲条件，
必须分别做实验，不能混成一个任务。

## 2. 五个高频疑问，先讲清楚

**Q1：为什么先截窗、再滤波？**
原实现是在截好的窗上做零相位滤波。如果先对整段 4.5 s 滤波再截窗，边界效应会不同，
数值就对不上。保持一致是复现的一部分。

**Q2：为什么 CS 按“重复编号”分折、NS 按“原始试次”分折？**
CS 的 12 次重复彼此独立，第 f 折取每个频率的第 f 次重复当测试，训练/测试天然不重叠。
NS 的 96 个 1 秒片段由 24 个（或 48 个）原始试次切出来，同一个 4 秒试次的 4 个相邻片段
高度相关。如果按片段随机分折，同一个试次的片段会同时出现在训练和测试集里——等于泄题。

**Q3：什么是“内部留一”？**
异步任务要用 CS 特征训练 LDA。某个训练试次的特征如果用它参与构建的模板来算，
相关会虚高（自己和自己比）。所以计算这个试次的特征时，先从模板/滤波器里把它剔除。
它只在外层训练集内部做，不碰外层测试数据。

**Q4：为什么子带要做加权，而不是取平均？**
SSVEP 能量主要在基频（低频子带），高频子带信噪比低、但受噪声影响也小。
权重 `w_m = m^(-1.25) + 0.25` 让低子带主导、高子带做补充证据。
权重值：`[1.25, 0.67, 0.50, 0.43]`。

**Q5：为什么结果可信？**
每一层都做到了“训练不碰测试”：
- 外层 12 折，折与折之间样本互斥；
- 模板/空间滤波器只用训练折；
- 内部留一进一步去掉“自己”，且只用训练折数据；
- OCN 的参数/频带选择只在训练折内的 3 折里做。
测试折标签从头到尾没有参与任何选择。

## 3. 逐模块导读

### 3.1 `ssvep/data.py`：从原始文件到干净数组

五个函数，按调用顺序：

```python
channel_table(config)              # 读 Channel Loc.xlsx → {电极名: 列号}
load_state(config, subject, state) # 读 MAT → 选通道 → preprocess → 缓存
crop_cs(config, cs, seconds)       # 从 0.14 s 起截窗
segment_ns(config, ns)             # NS 切成连续 1 秒片段，并记录所属原始试次
load_quality_response(...)         # 63 通道 12 Hz 平均响应（质量分析用）
```

**预处理三步**（`preprocess`）：

```python
x -= x.mean(axis=-1)                                  # 1. 去直流
x = resample_poly(x, 1, 5000 // 250, axis=-1)         # 2. 抗混叠降采样
x = filtfilt(*iirnotch(50, Q=30, fs=250), x)          # 3. 50 Hz 陷波
```

为什么不能“每 20 个点取 1 个”？那会把高频折叠到低频（混叠），
例如 200 Hz 干扰会伪装成 50 Hz。`resample_poly` 会先低通再抽点。

**缓存键**：文件名哈希包含源文件大小/修改时间、采样率、陷波参数、通道列表。
改任何一项都会生成新文件，所以永远不会读到过期缓存，也不需要手动清理。

### 3.2 `ssvep/algorithms.py`：四个公式

**(a) 滤波器组**

```python
order, critical = cheb1ord(passband, stopband, 3, 40, fs=250)
sections = cheby1(order, 0.5, critical, btype="bandpass", output="sos", fs=250)
filtered = sosfiltfilt(sections, signals, axis=-1)
```

`cheb1ord` 由通带/阻带指标反推最小阶数，`cheby1` 设计 Chebyshev I 滤波器，
`sosfiltfilt` 正反各滤一遍得到零相位（不产生时间延迟）。

**(b) CCA / FBCCA**

CCA 的几何含义：两个子空间之间最接近的一对方向，其夹角余弦就是典型相关系数。

```python
U = orthonormal_basis(signal)          # 信号的 [时间, 秩] 正交基
r = max_singular_value(U.T @ ref)      # 与参考基的最大相关
```

一个试次得到 `[4 子带, 8 候选频率]` 的相关矩阵，然后加权：

```
score[c] = Σ_m w_m · r[m, c]^p          p = score_power（频率识别用 1，选候选频率用 2）
```

**(c) TRCA / eTRCA**

对每个类别，用训练试次学一个空间滤波器 `w`：
让“试次之间重复出现的成分”尽量大、“试次内的噪声”尽量小。数学上是广义特征值问题：

```
Q = Σ_r X_r X_rᵀ                试次内协方差（噪声）
S = Σ_{r≠s} X_r X_sᵀ            跨试次协方差（信号）
S w = λ Q w，取 λ 最大的 w，归一化
```

`S` 用恒等式 `(ΣX_r)(ΣX_r)ᵀ - Q` 计算，避免二重循环。加一个相对迹的 1e-8 岭正则保证可解。

预测时：

```python
TRCA  ：每个类别用自己训练出的 w_c 投影，与模板比 Pearson 相关
eTRCA ：把 8 个类别的 w 拼成 8×通道 的大滤波器，一次性投影后再比相关
```

eTRCA 衡量的是“8 个类别的投影模式是否同时吻合”，更稳但容错低。

**(d) ITR**

```
ITR = [log2(N) + P·log2(P) + (1-P)·log2((1-P)/(N-1))] × 60 / T
```

`T` 是完整决策时间 = 观察窗 + 1.5 s 提示 + 0.14 s 视觉延迟；`P <= 1/N` 时记 0。

### 3.3 `ssvep/frequency.py`：八分类交叉验证

主循环只有两层：

```python
for seconds in windows:                    # 1、2、3、4 秒
    bank = filter_bank(crop_cs(cs, seconds))
    for fold in range(12):                 # 12 折
        model = fit_trca(bank[:, :, 训练重复])   # 只用 11 次重复
        for target in range(8):            # 8 个测试试次
            分数 = {FBCCA, TRCA, eTRCA}
            预测 = argmax(分数)
```

第 `f` 折的测试集是“每个频率的第 `f` 次重复”，所以每折正好 8 个测试样本；
12 折 × 8 频率 = 每人每窗每算法 96 条预测。FBCCA 不需要训练，
但为了记录格式一致，它也在同一折结构下打分。

### 3.4 `ssvep/asynchronous.py`：异步任务

**样本构成**

```
CS：8 频率 × 12 重复，每段截 0.14 s 后的 1 秒        → 96 个样本
NS：4 s 试次切 4 段 / 2 s 试次切 2 段                → 96 个样本
每个 NS 状态的任务 = 前 96 个 CS + 后 96 个 NS = 192 个样本
```

**分折与训练**

```
CS 样本的折号 = 它属于第几次重复
NS 样本的折号 = 原始试次编号 % 12      → 同一原始试次的片段必在同一折
```

每折要做的事：

```python
候选频率 = argmax_c Σ_子带 w·(eTRCA 相关)²        # 先粗选频率
LDA_c：CS(频率 c) vs 所有 NS，输入 4 维 eTRCA 相关   # 每个候选频率一个二分类器
预测 = c（若 LDA_c 判为 CS）否则 8（NS）

融合版：把 4 维 eTRCA 相关 + 4 维 FBCCA 相关拼成 8 维再训练 LDA
```

OCN 分支单独用 Fp1：先对 192 个样本各提取 80 维候选特征，
再在每折训练集内部选参数/选频带（见 3.5），最后线性 SVM 输出二分类。

### 3.5 `ssvep/ocn.py`：单通道也能建“网络”

```
1 秒信号（250 点）
  → 5 个频带分别滤波
  → 延迟嵌入：节点 i = (x[i], x[i+τ], ..., x[i+(d-1)τ])
  → 距离矩阵 D；若 D[i,j] <= r 则连边
  → 每个网络算两个数：平均度、平均聚类系数
  → 5 频带 × 8 组参数(τ,d,r) × 2 = 80 维候选特征
```

聚类系数的含义是“邻居之间也互相连边的比例”：
`(A²·A)_ii / (k_i·(k_i-1))`，度小于 2 的节点记 0。

选择规则（只在训练折内部）：

```python
3 折分层分组内层验证
  → 每个频带挑一个最好的 (τ,d,r)
  → 按内层准确率排序，取前 3 个频带
  → 6 维特征 → StandardScaler + 线性 SVM(C=1)
```

### 3.6 `ssvep/quality.py`：63 通道信号质量（图 4）

```python
每人先平均 12 次重复 → 预处理 → 取 0–4 s 做 FFT
幅度 = |rfft| × 2 / N           频率分辨率 0.25 Hz
SNR paper     = (2/Δf+1) · A(f) / Σ_{邻域含中心} A(k)     # 即 A(f) / 邻域均值
SNR neighbor  = A(f) / mean(邻域不含中心)                 # 诊断对照
```

然后取 12/24/36/48 Hz 的幅值，输出所有通道的表格和标准 10–20 坐标头皮图。
注意：地形图用的是**标准坐标**，不是实测电极位置。

### 3.7 `ssvep/report.py` 与 `ssvep/verify.py`

`report.py` 只做聚合：读每个人的 CSV → 核验 → 合并 → 画图 → 写 `REPORT.md`。
它不训练任何模型，所以可以单独重跑。

`verify.py` 是独立质检：从逐试次预测重新计算准确率/平衡准确率/ITR/检出率，
和 metrics CSV 对账；检查预测数量、分折规则、标签语义。它把协议常量写死
（12 折、96 条、192 条），协议一旦改动会直接报错而不是悄悄放过。

### 3.8 `run.py`

按阶段串起来：`audit → quality → frequency → async → report`。
只跑部分受试者/窗长时结果写到 `results/runs/<标签>/`，避免与全量结果混在一起。

## 4. 想动手改的时候

**加一种频率识别算法**
1. 在 `algorithms.py` 写一个返回 8 个分数的函数（输入 `[4, 通道, 时间]`）；
2. 在 `frequency.py` 的 `scores` 字典里加一行；
3. 在 `ALGORITHMS` 和 `report.py` 的 `FREQUENCY_ALGORITHMS` 里登记名字。

**只跑某些窗长**
`python run.py --windows 1 2`。ITR 的决策时间会自动跟着窗长变。

**改候选频带/网络参数**
改 `config.json` 的 `ocn.bands` / `delays` / `dimensions` / `radii` 即可，
特征缓存会因参数变化自动失效重算。

**观察中间结果**
`python quick_start.py` 会打印每个阶段的数组形状和相关矩阵，改代码前后都可以用它对照。

## 5. 读代码时容易误会的点

1. **CS 和 NS 的轴向不同**：预处理后 CS 是 `[频率, 重复, 通道, 时间]`，
   NS 是 `[原始试次, 通道, 时间]`。CS 多一维“频率”，是因为 CS 天生按 8 个频率组织。
2. **类别编号有两套**：频率识别和 FS 用 0–7 表示频率、8 表示 NS；
   IFB-OCN 只用 0=NS、1=CS。不要混用。
3. **`score_power` 有两个**：`filter_bank.score_power=1` 用于频率识别打分；
   `asynchronous.fs_score_power=2` 只用于异步里“选候选频率”。
4. **FBCCA 不训练**：它的“模型”就是参考信号，所以没有 fit 步骤，但仍按折记录。
5. **缓存不是算法的一部分**：删掉 `cache/` 只会变慢，不会改变任何结果。
6. **`results/` 与 `results/runs/`**：后者是只跑部分受试者时的输出，别拿它当全量结果。
